# Simple Interest Calculator

A lightweight, client-side **Simple Interest Calculator** built using standard **HTML5, CSS3, and vanilla JavaScript**. It allows users to quickly calculate the interest earned or owed on a principal amount over a specified period.

---

## 🚀 Features

- **Instant Calculations:** Computes interest instantly via standard client-side browser JavaScript.
- **Dynamic Accumulation:** Displays both the interest generated and the final total balance.
- **Form Validation:** Prevents negative inputs and ensures accurate numerical constraints.
- **Responsive Layout:** Optimized to look and function perfectly across desktops, tablets, and smartphones.

---

## 🧮 How It Works

The calculator operates using the standard simple interest formula:

$$I = P \times R \times T$$
$$A = P + I$$

Where:
- **$I$** = Total interest accrued
- **$A$** = Total final balance (Principal + Interest)
- **$P$** = Principal amount (initial investment or loan)
- **$R$** = Annual interest rate (Percentage divided by 100)
- **$T$** = Time duration in years

## ⚙️ Setup and Installation

No server-side configuration, dependencies, or installations are required. To run this project locally:

1. **Clone or Download** the project files into a folder.
2. Double-click the `index.html` file to open it instantly inside any modern web browser.

---

## 💡 Usage

1. Input your initial capital in the **Principal Amount ($)** field.
2. Enter the expected yearly rate in the **Annual Interest Rate (%)** field.
3. Specify the duration in the **Time Period (Years)** field.
4. Click **Calculate** to view your total interest generated and your ending balance breakdown.
5. Click **Reset** to clear all input fields for a new evaluation.
